# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称
- 可选“途经偏好”：多选想途经的景点，规划时会按顺序途经

### 2.3 热门路线模板
- 控制面板顶部预置了“夜景半日 / 亲子轻松 / 老街拍照 / 首次来渝”四条热门路线模板
- 点击模板会自动填入起点、终点与途经偏好，并立即调用后端算路
- 模板只是偏好配置，实际途经景点与顺序仍由后端根据图数据实时计算
- 填入后仍可手动修改起点/终点/途经偏好，再点“开始规划”重新计算

### 2.4 开始规划
- 点击“开始规划”
- 系统会计算最短路径并在地图上画出路线
- 下方“路径结果”显示途经景点顺序与总距离

### 2.5 常用操作
- “交换”：交换起点与终点
- “清空”：清除起点/终点/途经偏好与规划结果

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线，在控制面板查看路径节点列表与每段距离

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG"
# 带途经偏好：解放碑 → 洪崖洞 → 朝天门 → 南山一棵树
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=NANSHAN&via=HONGYADONG,CHAO_TIAN_MEN"
```
